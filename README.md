# Voice-Based Aspect-Based Sentiment Analysis

A voice-based Aspect-Based Sentiment Analysis system that combines speech-to-text, speech emotion recognition, and text-based ABSA.

## Pipeline

Voice Input
→ Speech-to-Text
→ Emotion/Tone Detection
→ Aspect-Based Sentiment Analysis
→ Aspect + Sentiment Output

## Technologies

- Python
- Whisper
- NLP
- DeBERTa
- Deep Learning
- Speech Emotion Recognition
- Cross-Modal Fusion

## Project Structure

- `notebooks/` - Training, evaluation and inference notebooks
- `models/` - Information about trained model files
- `dataset/` - Dataset information

## Note

Large trained model files and datasets are not included in this repository.
